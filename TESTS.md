# Тесты

Что покрыто тестами и как их запускать. Новый тестовый файл — строка в этот каталог.

**Полный прогон** — три команды из [README.md](README.md#тесты). Тестовый стек отдельный:
базы живут в памяти, наружу не открыт ни один порт, рабочие данные тесты не видят.

## Бэкенд — pytest

Запуск: `docker compose -f docker-compose.test.yml run --rm --build backend-tests`.
Перед тестами — линтер и проверка формата (ruff). Схема тестовой базы строится миграциями,
каждый тест работает в транзакции, которая откатывается.

| Файл | Что проверяет |
|---|---|
| `backend/tests/test_health.py` | эндпоинт здоровья: 200, когда база отвечает; 503, когда база недоступна |
| `backend/tests/test_migrations.py` | у миграций одна голова; откат и повторное применение работают; модели совпадают со схемой из миграций |
| `backend/tests/test_comments.py` | у каждого модуля бэкенда есть docstring |
| `backend/tests/test_books.py` | создание и каталог книг, рекомендации по жанру, пустой ввод и отсутствие результатов |
| `backend/tests/test_auth.py` | регистрация, хеш пароля, валидация и уникальность email, вход, текущий пользователь и выход |
| `backend/tests/test_favorites.py` | обязательный вход, добавление без дублей, удаление, неизвестная книга, сохранение после повторного входа и изоляция пользователей |
| `backend/tests/test_seed.py` | не менее 20 начальных книг, повторный запуск без дублей и сохранение пользовательской книги с совпавшим названием |

## Фронт — Vitest

Запуск: `docker compose -f docker-compose.test.yml run --rm --build frontend-tests`.
Перед тестами — ESLint, проверка типов и сборка. Сеть в тестах подменяет MSW:
обращение к незамоканному адресу роняет тест.

| Файл | Что проверяет |
|---|---|
| `frontend/src/App.test.tsx` | каталог и рекомендации; добавление и удаление избранного, ошибки API и приглашение гостю войти |
| `frontend/src/AuthPanel.test.tsx` | регистрация, ошибка входа и выход из восстановленной сессии |
| `frontend/src/comments.test.ts` | у каждого файла в `src` есть шапка-комментарий |

## E2E — Playwright

Запуск: `docker compose -f docker-compose.test.yml run --rm --build e2e`. Настоящий браузер
открывает фронт, фронт ходит в бэкенд, бэкенд — в тестовую базу.

| Файл | Что проверяет |
|---|---|
| `e2e/tests/smoke.spec.ts` | автоматический демонстрационный каталог и выбор жанра; API и рекомендации; регистрация и повторный вход; полный сценарий избранного с уникальными тестовыми данными |
